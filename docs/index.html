🚀 使い方（案件フォルダへの展開）

このディレクトリ内には個別案件のスライドを作成せず、別ディレクトリへコピーして作業します。

# 例: basic テンプレートで、ゼミ発表フォルダにスライドを作成
~/Base/プレゼン資料モデル/scripts/new-slide.sh basic ~/Base/ゼミ発表 "中間報告スライド"
